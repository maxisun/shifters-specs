# Research notes

Each file here answers one question against primary sources and records the date
it was answered. They are **dated snapshots**, not living documentation.

- Every claim is either a **Sourced fact** — traced to the standard, vendor, or
  tool that owns it — or a **Recommendation** with its trade-offs.
- End each note with a numbered `## Sources` section containing URLs.
- When a later change falsifies a note, **do not rewrite it**. Add a dated
  update block at the top of the affected section, say what changed, and name
  the observation that is superseded. The history is the point.
- When a recommendation is implemented, point at the implementation from the
  note, and point at the note from the guide or code that carries it.

Durable procedures live in `docs/guides/`. This directory keeps the reasoning;
`docs/guides/` keeps the steps.
