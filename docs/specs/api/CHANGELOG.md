# ShiftPatch API contract changelog

Contract releases use Semantic Versioning. Each published release is immutable;
changes to a published version require a new version and artifact.

## 1.0.0 — Initial contract baseline

- Establish the ShiftPatch MVP HTTP API surface for authentication, Facilities,
  Credentials, Nurses, Shifts, Timesheets, Dashboards, Audit, and Exports.
- OpenAPI dialect: 3.1.0.
- This is the first stable contract, so there is no earlier release to compare.
